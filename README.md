# acadally\_automizer





**A Bot Coded In Python to Automatically do the AcadAlly Quizzes. Created with the help of AI. Specifically Made For DPS Patna Students**





✨ Features



✅ Auto-opens AcadAlly in browser

✅ AI-powered answer selection

✅ Automatic question navigation

✅ Multiple selection methods

✅ Handles 25+ questions

✅ Auto-submits at the end

🔧 Technical Details
Uses Selenium for browser automation

Integrates with Nvidia NIM AI Studio API

Supports multiple question formats

Includes error handling and fallbacks
